# MediNear

MediNear is a healthcare platform designed to help users find nearby medical stores/pharmacies that have the medicines they need, especially during emergency situations.

## Features

- Find nearby pharmacies
- Search for medicines
- Check medicine availability
- Pharmacy/store management
- Location-based pharmacy search
- User authentication
- OCR-based medicine information
- AI-powered chatbot assistance
